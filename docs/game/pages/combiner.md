## Кратко

Сумматор (`ElectricalCombiner`, префаб `electrical.combiner.deployed`, предмет
`electrical.combiner`) выдаёт сумму входов. Это единственный способ сложить мощность
двух источников: [[logic-gates|OR]] даёт максимум, а не сумму. Потребление 0.

## Характеристики

| Параметр | Значение |
|---|---|
| Входы | 2: «Root Power 1», «Root Power 2», оба основные, оба `rootConnectionsOnly` |
| Выход | «Combined Power Out» |
| Потребление | 0 |
| Корневое устройство | да |
| Поиск петли | глубина `ioentity.backtracking × 2` = 16, `defaultReturn: true` |
| HP | 200 |

У класса три поля входов (`input1Amount…input3Amount`). Третий вход есть только у
жидкостного (`fluid.combiner.deployed`) и индустриального (`industrialcombiner.deployed`)
сумматоров того же класса.

## Поведение

```
для входа slot со значением > 0:
    если IsConnectedTo(this, slot, 16, defaultReturn: true): значение = 0, флаг Reserved7
выход = вход1 + вход2 (+ вход3)
```

- **Только от корней.** `WireTool` не даст подключить к входу сумматора устройство, у которого
  `IsRootEntity()` = false. Корневые: батарея, сплиттер, сумматор, солнечная панель, ветряк,
  водяное колесо, топливный и тестовый генераторы, нажимная плита, мишень.
- Выход отдаёт полную сумму, без деления.

## Нюансы

- **Ложное замыкание на длинных цепочках.** Если над входом 16 и больше устройств по основным
  входам (включая тех, кто заряжает батарею на входе), проверка исчерпает глубину и обнулит
  вход. Подробно — [[circuit-loops]].
- **Флаг замыкания отражает последний обновлённый вход.** Он сбрасывается, когда
  обновляется другой вход без петли.
- Индикатор «запитан» (`Reserved8`) смотрит только на входы 1 и 2 (`UpdateHasPower`).
- Нельзя подать в сумматор выход OR, ветвителя или выключателя напрямую — поставьте между
  ними [[splitter|сплиттер]] (он корневой).

## На практике

- Две батареи по 50 → сумматор → 100 rW на мощного потребителя.
- Солнечные панели в «гирлянду»: панель + панель → сумматор → сумматор + панель → … Каждое звено
  корневое, цепочка разрешена. Следите, чтобы над любым входом было не больше 15 устройств.
