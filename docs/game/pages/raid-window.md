## Кратко

Окно рейдов есть только в режиме softcore ([[game-modes]]): `RaidWindow.BlocksDamage` первым
делом проверяет, что включён `softcore.raidwindow_enabled` и активный режим — `GameModeSoftcore`.
Вне окна урон по постройкам **не гасится защитой, а отбрасывается целиком**: проверка стоит в самом
начале `BaseCombatEntity.Hurt`, до любых расчётов.

Окно считается по **реальному локальному времени машины сервера** (`DateTime.Now`), а не по
игровому времени суток. По умолчанию — каждый день с 18:00 до 21:00.

## Как работает

### Когда окно открыто (`RaidWindow.IsWindowOpen`)

```
начало = start − offset,  конец = end + offset   (обе по модулю 24)
если начало ≈ конец       → открыто всегда
если начало < конец       → открыто при начало ≤ час < конец
иначе (через полночь)     → открыто при час ≥ начало или час < конец
```

В субботу и воскресенье при `softcore.raidwindow_weekend_enabled` берутся свои часы
(по умолчанию 17–22). `softcore.raidwindow_hours_offset` расширяет окно в обе стороны:
offset = 1 при 18–21 даёт 17–22.

Режим раз в момент смены пересчитывает состояние (`GameModeSoftcore.UpdateRaidWindow`): ставит
флаг `Reserved4` на сущность режима, время следующей смены (`RaidWindowNextChangeAt`, unix UTC) и
обновляет у всех шкафов флаг «можно рейдить» (`BuildingPrivlidge.RefreshAllRaidStatus`). Следующая
смена ищется на 8 дней вперёд (`HorizonDays`).

### Кого защищает

Цель защищена, если это:

- строительный блок `BuildingBlock` (стены, полы, фундаменты, крыши, лестницы и т. д.);
- дверь (`Door`, включая двойные, гаражные, люки, решётки-двери);
- любая `DecayEntity`, связанная сокетом с блоком (`IsFrameInsert`): окна, решётки, ставни,
  гаражные ворота в рамах.

**Не защищены:**

- ворота `Gate` — это высокие внешние ворота (`gates.external.high.*`), исключены явно;
- высокие внешние стены — они `SimpleBuildingBlock`, а не `BuildingBlock`, под условие не попадают;
- двери осадной башни (`SiegeTowerDoor`);
- всё, что прикреплено к технике (`HasParentVehicle`), например постройки на лодках;
- **солома** — при `softcore.raidwindow_allow_twig` = true;
- деплои: ящики, шкаф, турели, печи — они не блоки и не двери.

### Какой урон блокируется

| Условие | Блокируется вне окна |
|---------|----------------------|
| В уроне есть `Explosion` (C4, ракеты, сачели, бобовки — всё, где в списке урона есть взрыв) | да |
| Ближний бой (`Blunt`, `Slash`, `Stab` — по основному типу) **по двери** | да, `softcore.raidwindow_block_melee_doors` |
| Тип `softcore.raidwindow_block_extra_type` по не-соломенному блоку | да, если `raidwindow_block_extra_enabled` |
| Огонь (`Heat`), стрелы, ближний бой по стенам | нет |

### Исключения

Даже вне окна урон проходит, если:

1. Атакующий **авторизован в шкафу** этой постройки (`softcore.raidwindow_allow_tc_authed`).
   Так можно перестраивать свою базу или добить базу после захвата шкафа.
2. Шкаф поставлен **меньше часа назад** (`softcore.raidwindow_fresh_tc_seconds` = 3600).
   Время установки `timePlaced` пишется в `BuildingPrivlidge.SetDeployedBy` только в softcore.

### MLRS

`MLRS.Fire` вне окна не стреляет вовсе и показывает подсказку, чтобы ракеты не пропали зря
(`softcore.raidwindow_block_mlrs`).

## Числа и настройки

| ConVar | По умолчанию | Смысл |
|--------|-------------|-------|
| `softcore.raidwindow_enabled` | true | окно включено |
| `softcore.raidwindow_start_hour` | 18 | начало, локальное время сервера |
| `softcore.raidwindow_end_hour` | 21 | конец |
| `softcore.raidwindow_weekend_enabled` | false | отдельные часы в сб и вс |
| `softcore.raidwindow_weekend_start_hour` / `_end_hour` | 17 / 22 | часы выходных |
| `softcore.raidwindow_hours_offset` | 0 | расширение окна в обе стороны, ч |
| `softcore.raidwindow_allow_twig` | true | солому можно ломать всегда |
| `softcore.raidwindow_allow_tc_authed` | true | авторизованным в шкафу можно всегда |
| `softcore.raidwindow_fresh_tc_seconds` | 3600 | «свежая» база рейдится час после установки шкафа |
| `softcore.raidwindow_block_melee_doors` | true | блок ближнего боя по дверям |
| `softcore.raidwindow_block_extra_enabled` | true | блок ещё одного типа урона по блокам |
| `softcore.raidwindow_block_extra_type` | 8 | номер типа урона (`Rust.DamageType`) |
| `softcore.raidwindow_block_mlrs` | true | MLRS не стреляет вне окна |
| `softcore.raidwindow_status` | — | админ-команда: текущее состояние окна |

## Нюансы

- **«Блок пуль» блокирует самоубийство.** Справка ConVar говорит: «8 = Bullet». Но в
  перечислении `Rust.DamageType` номер 8 — это `Suicide`, а `Bullet` — 9 (`Generic`, `Hunger`,
  `Thirst`, `Cold`, `Drowned`, `Heat`, `Bleeding`, `Poison`, `Suicide`, `Bullet`, …). Поэтому
  по умолчанию стрельба по постройкам вне окна **не блокируется**. Практического толку немного:
  защита от пуль у дерева 97 %, у камня 99 %, у металла 100 % ([[data-protection]]).
- **Высокие стены и ворота рейдятся когда угодно.** Ворота `Gate` исключены явно, а стены — не
  `BuildingBlock`. Внешний периметр защищён только своей прочностью.
- **Ближний бой по стенам не блокируется.** Блок melee стоит только для дверей. Мягкую сторону
  стены можно рубить вне окна (если она не соломенная, это долго, но возможно).
- **Огонь не блокируется.** Урона `Heat` (зажигательные ракеты и патроны, огнемёт) в списке нет.
  Камень и металл защищены от жара на 100 %, а деревянные блоки — на 90 %, так что огонь по
  дереву вне окна проходит ([[data-protection]]).
- **Окно привязано к часовому поясу машины.** `DateTime.Now` — локальное время ОС сервера. Если
  сервер стоит в другом поясе, окно для игроков сдвинуто. Таймер вайпа, наоборот, по умолчанию
  считает в `Europe/London` ([[wipe-and-saves]]).
- **Свежий шкаф забывается при рестарте.** `timePlaced` не сохраняется, а сравнивается с
  `Time.time`, который после перезапуска начинается с нуля. После рестарта поле равно 0, и
  исключение «свежий шкаф» перестаёт работать — база, поставленная за 5 минут до рестарта,
  сразу становится защищённой.
- **Шкаф без прав.** Если у блока нет шкафа вовсе, исключения не применяются, и блок защищён.
- **Признак «можно рейдить»** у шкафа (`Reserved7`) — только для интерфейса. Урон он не решает:
  `BlocksDamage` каждый раз пересчитывает всё заново.

## На практике

- Для рейда вне окна остаются: солома, высокие стены и ворота, огонь по дереву и деплоям.
- Сразу после установки шкафа у вас час уязвимости. Ставить шкаф лучше прямо перед рестартом
  сервера или вне окна, когда рядом никого нет.
- Если вы взяли чужой шкаф и авторизовались, можете ломать эту базу и вне окна.
