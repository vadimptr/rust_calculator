## Кратко

Таймер (`CustomTimerSwitch`, наследник `TimerSwitch`; префаб `timer`, предмет `electric.timer`)
— выключатель с задержкой отключения. Импульс на вход «Toggle On» или нажатие игроком включает
выход на `timerLength` секунд. Потребление 0.

## Характеристики

| Параметр | Значение | Источник |
|---|---|---|
| Вход 0 | Power In (основной) | префаб |
| Вход 1 | Toggle On (не основной) | префаб |
| Выход | Power Out | префаб |
| `timerLength` | 10 с по умолчанию | префаб `timer` |
| Шаг отсчёта | 0.1 с (`InvokeRepeating(AdvanceTime, 0, 0.1)`) | `StartTimer` |
| Потребление | 0 | `ConsumptionAmount` |
| HP | 200 | префаб |

Время меняет игрок с правом строительства (`CanBuild`) и только пока таймер **не идёт**
(`CanPlayerAdmin`). Сервер принимает любое число, кроме NaN и бесконечности
(`SERVER_SetTime`); ограничения диапазона — на стороне клиента.

## Поведение

```
Toggle On: новое значение > 0 → SwitchPressed()
нажатие игроком (SVSwitch)    → SwitchPressed()   // без права строительства, с 3 м

SwitchPressed(): если не идёт и запитан → старт, выход = вход − 0 (весь)
AdvanceTime (каждые 0.1 с): если прошло ≥ timerLength → стоп, выход 0
потеря питания во время отсчёта → стоп, выход 0
```

- **Не перезапускается.** Пока таймер идёт, новые импульсы игнорируются (`!IsOn()`).
  Продлить нельзя.
- `WantsPassthroughPower` = true, только когда таймер запитан и идёт: батарея видит
  потребителей за таймером лишь во время отсчёта.
- Отсчёт по `realtimeSinceStartup`, то есть по реальному времени сервера, с шагом 0.1 с.

## Нюансы

- **После рестарта начинает заново.** Сохраняется `timePassed`. Если он не 0,
  `PostServerLoad` вызывает `SwitchPressed()`, а `StartTimer` обнуляет счёт. Таймер на 1 час,
  прерванный рестартом на 59-й минуте, отработает ещё целый час.
- **Нажать может кто угодно** в 3 м с прямой видимостью: `SVSwitch` не требует права
  строительства. Менять время — только с правом.
- Вход Toggle реагирует на изменение значения, а не на фронт: 0 → 5 запустит, 5 → 7 тоже
  попытается (если таймер стоит).

## На практике

- Свет «на 30 секунд» по датчику: датчик → Toggle On, питание → Power In.
- Генератор импульсов из двух таймеров: выход первого через [[blocker|блокировщик]]
  запускает второй и наоборот.
- Длинные таймеры (часы) ненадёжны: рестарт отсчитывает время заново.

## Где в коде

`TimerSwitch.UpdateFromInput`, `SwitchPressed`, `StartTimer`, `AdvanceTime`, `EndTimer`,
`PostServerLoad`, `WantsPassthroughPower`; `CustomTimerSwitch.SERVER_SetTime`, `CanPlayerAdmin`.
