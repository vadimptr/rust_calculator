## Кратко

Кодовый замок хранит два кода и два списка игроков. Основной код (`code`) и основной список
(`whitelistPlayers`). Гостевой код (`guestCode`) и гостевой список (`guestPlayers`). Дверь открывает
тот, кто есть в любом из списков. Сам код при открытии не вводится: он нужен только чтобы
попасть в список.

## Характеристики

| Параметр | Значение | Откуда |
|----------|----------|--------|
| Длина кода | ровно 4 символа, только цифры | `RPC_ChangeCode`: `text.Length != 4 \|\| !text.IsNumeric()` |
| Ошибок до блокировки | 8 | `codelock.maxfailedattempts` |
| Длительность блокировки | 900 с (15 мин) | `codelock.lockoutcooldown` |
| Урон за n-ю ошибку | n × 5, тип `ElectricShock`, без брони | `UnlockWithCode` |
| Сброс счётчика ошибок | через 60 с без ошибок | `UnlockWithCode` |
| Предупреждение о блокировке | с 6-й ошибки | `wrongCodes > 5` |
| Дистанция | 3 м | `RPC_Server.MaxDistance(3f, CheckParent = true)` |
| Куда ставится | слот `Lock`: двери, ящики, шкаф | [[locks]] |
| Рецепт | 100 Metal Fragments, 30 с, без верстака, известен сразу | [[data-crafting]] |
| Снятие | разрешено (`CanRemove = 1` в префабе `lock.code`) | `BaseLock.RPC_TakeLock` |
| HP | нет: замок — `BaseEntity`, урона не получает, ломают дверь | префаб |

## Поведение

### Установка кода

`RPC_ChangeCode` работает только на **незапертом** замке.

- **Основной код.** Записывается, основной список очищается, в нём остаётся только тот, кто
  поменял код. Если основного кода раньше не было, замок сразу запирается.
- **Гостевой код.** Можно задать, только если основной уже есть. Гостевой список очищается,
  в него попадает установивший.

### Ввод кода

`UnlockWithCode` работает только на **запертом** замке и только если ввод не заблокирован.

- Верный основной код: игрок добавляется в основной список, счётчик ошибок обнуляется.
- Верный гостевой код (если он задан): игрок добавляется в гостевой список. Счётчик ошибок
  при этом **не** обнуляется.
- Неверный код: удар током, счётчик +1, после 8 ошибок — блокировка.

### Запереть и отпереть

`TryLock` и `TryUnlock` доступны только **основному** списку. Гость может открывать дверь,
но не может отпереть или запереть замок, а значит, не может сменить код.

### Открытие двери / ящика

`OnTryToOpen` и `OnTryToClose`: если замок не заперт, пускают всех. Если заперт — только
игроков из любого из двух списков. Проигрываются эффекты «открыто» или «отказ».

### Сохранение

Коды и списки пишутся только в сохранение на диск (`info.forDisk`). Клиент получает лишь
флаги «код есть», «гостевой код есть», «ты в списке», «ты гость». Сам код клиентам не уходит.

## Нюансы

- **Блокировка общая.** Флаг `Reserved11` (`Flag_CodeEntryBlocked`) стоит на замке. 15 минут код
  не введёт никто, даже хозяин, но хозяин из списка при этом открывает дверь как обычно.
- **Шесть ошибок подряд убивают.** 5+10+15+20+25+30 = 105 при 100 HP у игрока. Броня не помогает.
- **Рестарт сервера снимает блокировку** (`PostServerLoad`).
- **Счётчик ошибок не сохраняется.** `wrongCodes` — обычное поле, в сохранение не пишется.
- **Перекодировать открытый замок может любой.** Проверяется только `!IsLocked()`.
- **Подбор стирает всё.** `RPC_TakeLock` возможен только на отпертом замке и выдаёт новый
  предмет без кодов.
- **Перекраска и апгрейд двери сохраняют коды.** `Reskin_Preserve` / `Reskin_Restore` переносят
  коды, оба списка и состояние «заперт».
- **Пользователи замка платят налог.** Если в замке двери больше 2 пользователей
  (`decay.upkeep_lock_min_users`), они считаются в размер группы шкафа ([[upkeep]]). Любое
  изменение списков вызывает пересчёт (`MarkGroupUpkeepDirty`).
- **Ящики с дисплеем обновляются.** Если замок висит на `DisplayingBoxStorage`, смена кода
  и новые пользователи шлют ящику сетевое обновление (`UpdateParentBox`).

## На практике

- Гостевой код раздавайте тем, кому нужен только проход: гость не сменит код и не отопрёт замок.
- Чтобы выгнать всех, отоприте замок и задайте новый основной код.
- Если ввод заблокирован, а вы в списке, дверь всё равно откроется. Ждать 15 минут нужно
  только тем, кому надо ввести код.

## Где в коде

- `CodeLock.RPC_ChangeCode`, `UnlockWithCode`, `TryLock`, `TryUnlock` — основное поведение.
- `CodeLock.OnTryToOpen`, `OnTryToClose`, `GetPlayerLockPermission` — допуск.
- `CodeLock.ClearCodeEntryBlocked`, `PostServerLoad` — блокировка ввода.
- `CodeLock.Save`, `Load`, `Reskin_Preserve`, `Reskin_Restore` — сохранение и перенос.
