## Кратко

Замок — отдельная сущность, прикреплённая к слоту `Lock` двери, ящика, шкафа или другого
контейнера. Хозяин слота ничего не решает сам: он спрашивает замок. Дверь зовёт
`OnTryToOpen` / `OnTryToClose`, ящик и шкаф — `OnTryToOpen`.

Общий предок — `BaseLock`. Без наследника он пускает всех, когда не заперт.
Наследников два:

- `CodeLock` — список допущенных по Steam ID. Попасть в список можно только вводом кода.
- `KeyLock` — ключ-предмет с числовым кодом. Без ключа пускает только того, кто поставил замок.

Права строительства и авторизация в шкафу на замок **не влияют**. Это разные системы.

## Как работает

### Установка

Замок ставится через `Deployer.DoDeploy_Slot`. Сервер проверяет:

1. У игрока есть право строить там, где он стоит (`CanBuild()`), и он не в зоне монумента.
2. У цели есть слот `Lock` (`HasSlot`) и он пуст.
3. До цели не больше 3 м.
4. Игрок может строить в границах цели (`CanBuild(baseEntity.WorldSpaceBounds())`).

Слот `Lock` есть у двери, если в префабе `canTakeLock = true`. По ассетам флаг стоит у всех дверей
игрока (одинарных и двойных), люков, гаражной двери, высоких ворот, двери камеры, калитки
забора и витрины. Нет его у деревянных ставней и у дверей монументов. У контейнера слот есть,
если `isLockable`. У шкафа (`BuildingPrivlidge`) он есть всегда.

Владельцем замка (`OwnerID`) становится тот, кто его поставил.

### Кто может открыть

| Замок | Открывает | Запирает / отпирает | Меняет код / делает ключ |
|-------|-----------|---------------------|--------------------------|
| Кодовый, не заперт | все | основной список, если код задан | любой, кто дотянулся (смена кода) |
| Кодовый, заперт | основной список и гости | только основной список | никто (сначала отпереть) |
| Ключевой, не заперт | все | владелец или ключ | любой (ключ) |
| Ключевой, заперт | владелец или ключ | владелец или ключ | владелец или ключ |

Подробности по каждому замку — в [[code-lock]] и [[key-lock]].

### Снятие

`BaseLock.RPC_TakeLock`: замок можно снять, только когда он **не заперт** и `CanRemove = true`.
Игрок получает **новый** предмет замка. Коды, списки допущенных и код ключа не сохраняются.

### Неверный код

Каждая ошибка на кодовом замке бьёт током: `(wrongCodes + 1) * 5` урона, тип `ElectricShock`,
**без учёта брони** (`useProtection: false`). Счётчик `wrongCodes` сбрасывается, если с прошлой
ошибки прошло больше 60 с. После 6-й ошибки подряд игрок видит предупреждение. После
`codelock.maxfailedattempts` (8) ошибок замок блокирует ввод кода на `codelock.lockoutcooldown`
(900 с = 15 мин).

### Замки и содержание базы

С групповым налогом на содержание ([[upkeep]]) замки связаны напрямую. Если
`decay.upkeep_group_count_locks = true` (по умолчанию), шкаф считает в размер группы всех,
кто записан в кодовые замки **дверей** здания: основной список и гостей. Но только если
у замка больше `decay.upkeep_lock_min_users = 2` пользователей. Игроки, уже авторизованные
в шкафу, повторно не считаются. После выписки из замка игрок ещё
`decay.upkeep_group_window_hours = 24` ч числится в группе.

Каждая смена кода и каждый новый пользователь замка вызывает `RecalculateGroupUpkeep` у шкафа.

## Числа и настройки

| ConVar / константа | По умолчанию | Смысл |
|--------------------|--------------|-------|
| `codelock.maxfailedattempts` | 8 | Ошибок до блокировки ввода |
| `codelock.lockoutcooldown` | 900 с | Длительность блокировки ввода |
| Урон током за ошибку | `(n) * 5`, где n — номер ошибки | `CodeLock.UnlockWithCode` |
| Окно сброса счётчика ошибок | 60 с | `CodeLock.UnlockWithCode` |
| Длина кода | ровно 4 цифры | `CodeLock.RPC_ChangeCode` |
| Код ключевого замка | случайное от 1 до 99 999 | `KeyLock.OnDeployed`, `Random.Range(1, 100000)` |
| Дистанция работы с замком | 3 м (с учётом родителя) | `RPC_Server.MaxDistance(3f, CheckParent = true)` |
| `decay.upkeep_group_count_locks` | true | Считать пользователей замков в группу |
| `decay.upkeep_lock_min_users` | 2 | Замок с ≤ 2 пользователями не учитывается |
| `decay.upkeep_group_window_hours` | 24 | Сколько часов игрок числится в группе |

## Нюансы

- **Блокировка ввода — на замке, а не на игроке.** Подсказка к ConVar говорит «игрок заблокирован»,
  но код ставит флаг `Reserved11` на сам замок. 15 минут код не может ввести **никто**, включая
  хозяина. Хозяин из списка при этом спокойно открывает дверь: `OnTryToOpen` флаг не проверяет.
  Не может он только отпереть или запереть замок (`TryUnlock` / `UnlockWithCode`).
- **Перезагрузка сервера снимает блокировку.** `CodeLock.PostServerLoad` сбрасывает флаг.
- **Шесть ошибок подряд — смерть.** 5 + 10 + 15 + 20 + 25 + 30 = 105 урона при 100 HP
  (`StartMaxHealth() = 100`), броня не помогает. Предупреждение появляется только после 6-й ошибки.
  До блокировки (8 ошибок) свежий игрок без лечения не доживает.
- **Пауза в минуту обнуляет счётчик.** Если между ошибками прошло больше 60 с, удар снова 5.
- **Отпертый кодовый замок может перекодировать кто угодно.** `RPC_ChangeCode` проверяет только
  `!IsLocked()`. Новый основной код стирает весь основной список, в нём остаётся только тот,
  кто код сменил.
- **Первый код запирает сразу.** Если основного кода ещё не было, его установка ставит `Locked`.
- **Ключевой замок нельзя «потерять».** Владелец (`OwnerID`) проходит всегда, даже без ключа.
- **Сделать ключ — значит его скрафтить.** `KeyLock.RPC_CreateKey` проверяет рецепт
  (`CanCraft`) и ставит крафт в очередь. Первый ключ запирает замок.
- **Взлома нет.** В серверном коде нет механики отмычки для этих замков. Пройти можно только
  с кодом, ключом или через уничтожение двери.
- **Код не переносится при подборе.** `RPC_TakeLock` создаёт новый предмет. Зато при апгрейде
  или перекраске двери коды сохраняются (`CodeLock.Reskin_Preserve` / `Reskin_Restore`).

## На практике

- Не перебирайте коды: шестая ошибка подряд убивает, а восьмая на 15 минут запирает ввод для всех.
- Чтобы сменить код, сначала отоприте замок. Пока замок открыт, перекодировать его может
  любой, кто подошёл. Не оставляйте замок незапертым.
- Большой клан, раздающий коды от дверей, платит за это повышенный налог содержания,
  даже если никого не авторизовал в шкафу.
- Нужно убрать доступ у всех — смените основной код: список допущенных обнулится.

## Где в коде

- `BaseLock.OnTryToOpen`, `BaseLock.RPC_TakeLock`, `BaseLock.GetPlayerLockPermission` — общее поведение.
- `CodeLock.RPC_ChangeCode`, `UnlockWithCode`, `TryLock`, `TryUnlock`, `ClearCodeEntryBlocked` — кодовый замок.
- `KeyLock.HasLockPermission`, `RPC_CreateKey`, `OnDeployed` — ключевой замок.
- `Deployer.DoDeploy_Slot` — установка в слот.
- `BuildingPrivlidge.RefreshDoorGroupMembers`, `RecalculateGroupUpkeep` — замки и налог на группу.
