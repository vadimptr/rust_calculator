## Кратко

У предмета с прочностью два числа: `condition` (сейчас) и `maxCondition` (до скольки можно
починить). Оба ограничены заводским максимумом `info.condition.max` из ассета. Ремонт
возвращает `condition` к `maxCondition`, но сам `maxCondition` при этом уменьшается — тем
сильнее, чем ниже была прочность. Предмет, сломавшийся при `maxCondition ≤ 5`, исчезает. Ремонт построек молотком — отдельная механика, см. [[repair]].

## Как работает

### Потеря прочности

Всё сводится к `Item.LoseCondition(amount)`. Кто и сколько отнимает (по коду):

| Источник | Потеря |
|----------|--------|
| Выстрел огнестрела (`BaseProjectile.UpdateItemCondition`) | `0,25 + barrelConditionLoss` патрона; моды на оружии теряют то же × `ConditionLossMultiplier` мода |
| Удар оружием ближнего боя (`BaseMelee.UpdateItemCondition`) | `GetConditionLoss()` (по умолчанию 1) + 0,2 × урон, который «съела» броня цели |
| Добыча ресурсов (`ResourceDispenser`, см. [[gathering]]) | `conditionLost` из настроек добычи |
| Броня и одежда (`ItemModWearable`, см. [[armor-clothing]]) | сумма по типам урона `урон × защита предмета от этого типа`, не больше текущей прочности |
| Факел | 1/12 за тик горения |
| Ракетница, гранатомёт (`BaseLauncher`) | случайно 1–2 за выстрел |

Числа «на предмет» (`barrelConditionLoss`, `conditionLost`, защиты) лежат в ассетах. По
выгрузке `barrelConditionLoss` = 0 у всех патронов, кроме разрывных 5.56 (`ammo.rifle.explosive`,
0,5): обычный выстрел снимает 0,25, разрывной — 0,75 прочности.

Заводской максимум (`condition.max` в `ItemDefinition`), примеры: автомат и MP5 — 150,
болтовка и полуавтоматический пистолет — 100, топор и кирка — 400, отбойный молоток — 300,
металлическая маска — 320.

### Поломка

Когда прочность падает до нуля, `Item.OnBroken`:

- предмет в руках получает флаг `Broken` и не может быть взят в руки (`CanBeHeld`);
- если предмет **не ремонтируемый** (`repairable = false` и нет `ItemModRepair`) **или**
  `maxCondition ≤ 5` — он **удаляется** (у оружия сначала выгружаются патроны);
- шлем, сломавшийся от смертельного удара, слетает с головы и падает рядом
  (`ItemModWearable`).

Сломанные предметы не используются как ингредиенты крафта (`takeBroken: false`).

### Ремонт на верстаке ремонта

`RepairBench.RepairAnItem`:

1. Нужен рецепт предмета; предмет должен быть `repairable` и не полностью целым.
2. **Нужно знать рецепт** (или он не исследуемый). Исключение — режим игры с
   `canRepairIfCraftingBanned`.
3. Список стоимости — ингредиенты рецепта. Компоненты (`ItemCategory.Component` или
   `treatAsComponentForRepairs`) **заменяются первым ингредиентом своего рецепта**
   (например, деталь → её основной ресурс) в количестве `ингредиент × число компонентов`.
4. Цена каждого ресурса:
   ```
   доля_ремонта = 1 - condition / maxCondition
   цена = ceil(количество_в_списке * доля_ремонта * 0.2)
   ```
5. Если всего хватает — ресурсы списываются и вызывается `Item.DoRepair`.

### Потеря максимума

`Item.DoRepair(maxLossFraction)`:

```
износ        = 1 - condition / maxCondition
maxCondition = maxCondition * (1 - maxLossFraction * износ)
condition    = maxCondition
```

`maxLossFraction` — `RepairBench.maxConditionLostOnRepair` (поле, по умолчанию 0,2) или
`ItemModRepair.conditionLost` (0,05), если у предмета есть этот мод. В обоих префабах
верстака ремонта (`repairbench_deployed`, `repairbench_static`) `maxConditionLostOnRepair` = 0,2.
Если у предмета в ассете `maintainMaxCondition`, максимум не теряется вообще: так у всех
деплоев (ящики, печи, шкаф, турели, SAM, модули машин) и нескольких праздничных костюмов,
но ни у одного оружия, инструмента или брони.

| Ремонт при прочности | Цена от рецепта | Потеря максимума (при 0,2) |
|----------------------|-----------------|----------------------------|
| 90 % | 2 % | 2 % |
| 50 % | 10 % | 10 % |
| 10 % | 18 % | 18 % |
| 0 % (сломан) | 20 % | 20 % |

### «Перезаправка» предметов с ItemModRepair

У части предметов есть `ItemModRepair` и команда `refill`: ремонт прямо в инвентаре, без
ресурсов, если уровень верстака игрока не ниже `workbenchLvlRequired` и игрок не плывёт.
Потеря максимума — `conditionLost` (0,05). Мод есть у четырёх предметов: баллоны для
дайвинга (`diving.tank`, `diving.tank.double`) и отбойный молоток (`jackhammer`) —
верстак 1; очки ночного видения (`hat.nvg`) — верстак 2.

### Прочность найденных предметов

В ящиках типа `TOWN` и `ROADSIDE` ([[loot-spawns]]) прочность случайна в пределах
`foundCondition` ассета предмета (доли от максимума):

| Предметы | Найденная прочность |
|----------|---------------------|
| Автоматы и ПП (`rifle.ak` и скины, `smg.mp5`, `smg.thompson`, `rifle.semiauto`, `lmg.m249`, `hmlmg`, `minigun`) | 10–20 % |
| LR-300, M16A2, модули машин | 50–100 % |
| M92 | 20–30 % |
| Арбалеты, гарпунное ружьё, духовая трубка | 20–50 % |
| Детали двигателя | 25–75 % |
| Python, двустволка, мушкетон, револьвер HC | ровно 10 % |
| Болтовка, L96 | 1–5 % |
| Помповые и автоматические дробовики | 1–3 % |
| Огнемёты | 0–2 % |
| Остальное (367 предметов) | 100 % |

## Числа и настройки

| Что | Значение | Где |
|-----|----------|-----|
| Доля цены рецепта | 0,2 | `RepairBench.REPAIR_COST_FRACTION` / `RepairCostFraction` |
| Потеря максимума на верстаке | 0,2 × износ | `RepairBench.maxConditionLostOnRepair` (поле и префаб) |
| Потеря при `refill` | 0,05 × износ | `ItemModRepair.conditionLost` (поле и префабы) |
| Порог уничтожения | `maxCondition ≤ 5` | `Item.OnBroken` |
| Износ за выстрел | 0,25 + `barrelConditionLoss` (0, у разрывных 5.56 — 0,5) | `BaseProjectile.UpdateItemCondition` |
| Отладка | `debug.disablecondition` | отключает потерю прочности |

## Нюансы

- **Когда чинить — почти всё равно.** И цена, и потеря максимума линейны по износу. Десять
  ремонтов с 90 % срежут максимум до 0,98¹⁰ ≈ 0,817, один ремонт с нуля — до 0,8: на
  одинаковый суммарный износ разница меньше двух процентов, ресурсы те же. Ранний ремонт
  выигрывает другим: предмет не ломается в бою и не рискует исчезнуть при `maxCondition ≤ 5`.
  По сути, каждые 100 % износа обходятся примерно в 20 % максимума, как ни дели ремонты.
- **Компоненты не нужны.** Для ремонта не требуются шестерни, пружины и т. п.: они заменены
  своим базовым ресурсом. Сами компоненты из инвентаря не берутся.
- **Без изучения рецепта не починить.** Найденное оружие, рецепт которого вы не знаете,
  верстак ремонта не примет. Исключение — неисследуемые предметы.
- **«Сломан навсегда» при ≤5 максимума.** Предмет, у которого после ремонтов максимум упал
  до 5 и ниже, при следующей поломке исчезнет.
- **Предметы с `ItemModRepair` чинятся на верстаке бесплатно.** Если у предмета этот мод
  с флагом `canUseRepairBench`, `GetRepairCostList` возвращает пустой список: ремонт
  на верстаке ремонта ничего не стоит, но максимум всё равно теряется на `conditionLost`.
- **Модули на оружии тоже изнашиваются** ([[weapon-attachments]]). Каждый выстрел снимает прочность и с модов,
  с их собственным множителем.
- **Ремонт портит переработку.** Переработчик учитывает текущий максимум относительно
  заводского ([[recycling]]): многократно чиненный предмет отдаёт меньше.
- **Найденное на дорогах и в городе — уже изношенное** (`foundCondition`, см. [[loot-spawns]]).
- **Крафт по чертежу-предмету даёт половину прочности**: `maxCondition × 0,5` (см. [[crafting]]).

## На практике

- Чините до того, как предмет сломается: по ресурсам и потере максимума это почти то же
  самое, но сломанный предмет нельзя взять в руки, а при низком максимуме он исчезнет.
- Перед переработкой не чините: ремонт уменьшит выход переработчика.
- Броня изнашивается пропорционально защите, которую она дала. Сильно побитый шлем
  может слететь при смертельном попадании.

## Где в коде

- `Item.LoseCondition`, `Item.OnBroken`, `Item.DoRepair` — прочность и поломка.
- `RepairBench.RepairAnItem`, `RepairBench.GetRepairCostList`, `RepairBench.StripComponentRepairCost` — ремонт.
- `ItemModRepair.ServerCommand` — «refill».
- `BaseProjectile.UpdateItemCondition`, `BaseMelee.UpdateItemCondition`, `ItemModWearable` — износ.
