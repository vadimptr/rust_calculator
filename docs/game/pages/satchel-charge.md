## Кратко

Сачель — это `DudTimedExplosive`, наследник `TimedExplosive` (префаб `explosive.satchel.deployed`).
Взрывается он так же, как C4: флаг `onlyDamageParent` стоит в префабе, поэтому и поставленный,
и брошенный прилипший сачель бьёт только свой блок (см. [[explosions]]). Но у него две
особенности: **случайная длина фитиля** и **осечка**. При каждой попытке взрыва бросается
кубик, и с вероятностью `dudChance = 0.2` заряд гаснет, а не взрывается.

## Характеристики

| Параметр | Значение | Источник |
|----------|----------|----------|
| Класс | `DudTimedExplosive` | компонент префаба `explosive.satchel.deployed` |
| Шанс осечки | **20 %** (`dudChance = 0.2`; умолчание класса 0.4) | префаб |
| Базовый фитиль | 6–12 с | `timerAmountMin = 6`, `timerAmountMax = 12` в префабе |
| Множитель фитиля | ×0.334 с шансом 15 %, ×3 с шансом 12.75 %, иначе ×1 | `DudTimedExplosive.GetRandomTimerTime` |
| Итоговый фитиль | 2–4 с (15 %), 6–12 с (72.25 %), 18–36 с (12.75 %) | префаб × множитель |
| Урон | 75 Explosion + 200 Blunt + 200 Stab | `damageTypes` префаба |
| Урон по игрокам | 400 Explosion | `playerDamage` префаба |
| Радиусы | 0 и 4 м | `minExplosionRadius`, `explosionRadius` в префабе |
| Только родитель | да | `onlyDamageParent = 1` в префабе |
| Гаснет в воде сам | нет | `becomeDudInWater = 0` в префабе |
| Бросок | 10 м/с | `maxThrowVelocity` оружия `explosive.satchel.entity` |
| Жизнь несработавшего заряда | 1200 с (20 мин) | `BecomeDud → Invoke(KillMessage, 1200f)` |

Все значения — в [[data-explosives]].

## Поведение

### Фитиль

`GetRandomTimerTime`:

```csharp
float t = base.GetRandomTimerTime();          // Random(timerAmountMin, timerAmountMax)
if (Random.Range(0f,1f) <= 0.15f) t *= 0.334f; // 15 %: в три раза быстрее
else if (Random.Range(0f,1f) <= 0.15f) t *= 3f; // 0.85 × 0.15 = 12.75 %: в три раза дольше
```

Итого: 15 % — короткий фитиль, 12.75 % — длинный, 72.25 % — обычный.

### Осечка

`DudTimedExplosive.Explode`:
- если создатель — NPC, взрыв **всегда** (у NPC осечек нет);
- иначе `Random(0,1) < dudChance` → `BecomeDud()`, иначе обычный взрыв.

`BecomeDud`:
- гасит фитиль (флаг `On` снят), проигрывает эффект шипения;
- если какой-то предок в цепочке родителей движется (`syncPosition`, например техника),
  заряд отцепляется и падает. На неподвижной стене остаётся висеть;
- через 1200 с заряд удаляется.

### Что можно сделать с несработавшим зарядом

- **Подобрать** (`RPC_Pickup`, дистанция до 3 м, только если фитиль не горит):
  - если заряд к чему-то прилип (`HasParent`), то с вероятностью 50 % вместо подбора
    **заново зажигается фитиль на 2.5–3 с**;
  - иначе игрок получает предмет `itemToGive` обратно.
- **Поджечь снова** — через интерфейс `IIgniteable`. В коде это делает электрический
  поджигатель (`Igniter.IgniteInRange`). Новый фитиль снова случайный, по `GetRandomTimerTime`.
- Каждый перезапуск ведёт к новому `Explode()` и **новому броску на осечку**.

### Вода

- `WantsSplash` / `DoSplash`: если плеснуть водой на **горящий** заряд, он становится
  несработавшим, и взрыв отменяется.
- Если в префабе `becomeDudInWater`, заряд проверяет воду раз в 0.5 с и гаснет при
  `WaterFactor() >= 0.5`. Брошенный NPC — взрывается. **У сачеля этот флаг выключен**,
  так что под водой он сам не гаснет — только от плеска водой.

## Нюансы

- **Осечка проверяется в момент взрыва, а не при броске.** Пока фитиль горит, исход неизвестен.
- **Шанс осечки — 20 %.** Умолчание класса 0.4, но в префабе `explosive.satchel.deployed`
  стоит `dudChance = 0.2`.
- **Ожидаемый расход.** Если на блок нужно `N` срабатываний, в среднем уходит `N / 0.8`
  зарядов, если несработавшие не поджигать: на камень 12.5 вместо 10, на металл 28.75
  вместо 23. Перезапуск подбором (50 %) и поджигателем позволяет вернуть часть зарядов.
- **Против игроков сачель другой.** По игрокам идёт не смесь трёх типов, а `playerDamage` —
  400 Explosion.
- **Подбирать несработавший заряд с двери опасно.** В половине случаев вы не получите
  предмет, а запустите фитиль на 2.5–3 с у себя перед лицом.
- **Не прилипает, если фитиль не горит.** `CanStickTo` требует горящего фитиля.
- **`ForceExplode` убирает осечку.** Принудительный взрыв (катапульта, защита от прохода
  сквозь стену) обнуляет `dudChance`.
- **Висящий несработавший заряд блокирует перекраску и поворот блока**, пока он существует
  (`CanBeReskinned`, `IsRotationBlocked` ищут дочерний `TimedExplosive`).
- **В приложении (замечание).** В `splash.ts` у сачеля `area: false`, как у C4. Это совпадает
  с префабом (`onlyDamageParent = 1`). Осечки не моделируются: количество в `raidData.ts`
  (3 / 10 / 23 / 46) — целое число срабатываний без запаса. С осечкой 20 % в среднем нужно
  в 1.25 раза больше: 3.75 / 12.5 / 28.75 / 57.5 сачеля.

## На практике

- Берите запас сачелей на осечки: в среднем каждый пятый не взорвётся с первого раза,
  то есть нужно +25 % к расчётному числу.
- Несработавший сачель на стене лучше поджечь поджигателем или подобрать и поставить
  заново. Учтите 50 % шанс, что он взорвётся через 2.5–3 с.
- Защитнику полезно плеснуть водой на горящий сачель: это гарантированно гасит его.
