## Кратко

Промышленный сплиттер — это обычный класс `Splitter`, а объединитель — `ElectricalCombiner`.
Различие только в префабах: `ioType = Industrial` и промышленные порты. Питания и логики
у них нет. Промышленный вход вызывает лишь `IOStateChanged`
(`IOEntity.UpdateFromInput`), так что электрические формулы деления к ним не относятся.
Для конвейера они прозрачны: обход сети просто проходит через них
(`IOEntity.FindContainerSource`).

## Характеристики

| Параметр | Сплиттер | Объединитель |
|----------|----------|--------------|
| Порты | вход Industrial In; выходы Out 1–3 | входы In 1–3; выход Industrial Out |
| HP | 200 | 200 |
| Рецепт | 75 фрагментов, верстак 1 | 75 фрагментов, верстак 1 |
| Питание | не нужно | не нужно |
| Подбор | права в шкафу + молоток | то же |

## Поведение

### Деление — «поровну на всех», а не «по веткам»

Конвейер находит за собой N хранилищ (не больше 32) и каждому даёт порцию
`(int)(min(60, stackable) / N)` из каждой стопки. Где стоят сплиттеры, значения не имеет:

```
Конвейер ─► Сплиттер ─┬─► Ящик A
                       ├─► Ящик B
                       └─► Сплиттер ─┬─► Ящик C
                                     └─► Ящик D
N = 4 → каждый ящик получает по 15 из стопки за тик (а не A/B по 20, C/D по 10).
```

Поле `ContainerInputOutput.MaxStackSize` (порция, делённая по веткам) вычисляется,
но нигде не используется.

### Объединитель

Объединяет источники для одного конвейера. Конвейер просматривает все источники
в порядке обхода и предметы в каждом из них. Один и тот же предмет второй раз не берётся,
даже если контейнер виден по двум путям.

## Нюансы

- **Неподходящие получатели крадут долю.** Если один из N получателей — печь, которая не
  примет камень, остальные всё равно получают камень порциями `60 / N`.
- **Порядок важен при малых стопках.** Получатели обрабатываются по очереди в порядке обхода
  (выход 1 → 2 → 3, вглубь). Стопка меньше порции целиком уходит первому.
- **Один контейнер через два адаптера — это два получателя:** ему достанется двойная доля.
  Одно и то же хранилище учитывается не больше 2 раз.
- **Сплиттер нельзя поставить после второго конвейера, чтобы удвоить скорость.** Обход
  останавливается на конвейере, и второй конвейер видит только свои ближайшие хранилища.
- Сплиттер и объединитель держатся на земле: у префабов есть `DestroyOnGroundMissing`.

## На практике

- Хотите неравное распределение — используйте **отдельные конвейеры** с фильтрами Max
  на каждое направление, а не дерево сплиттеров.
- При 3 печах и 1 ящике руды порция руды на печь — 20 из каждой стопки за ~5 с.
  Для быстрой загрузки держите руду в нескольких стопках: каждая стопка отдаёт свою порцию.
