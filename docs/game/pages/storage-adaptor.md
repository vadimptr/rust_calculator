## Кратко

Адаптер (`IndustrialStorageAdaptor`, префаб `storageadaptor.deployed`) — дочерняя сущность
контейнера. Его хранилище — это инвентарь родителя (`StorageContainer.inventory` или
`ContainerIOEntity.inventory`). Диапазоны слотов он берёт у родителя, если тот их задаёт
(печь, шкафчик). Иначе разрешён весь инвентарь. См. [[industrial-system]].

## Характеристики

| Параметр | Значение | Источник |
|----------|----------|----------|
| HP | 30 | `startHealth` в префабе |
| Рецепт | 100 фрагментов металла, верстак 1, 30 с | чертёж `StorageAdaptor.item` |
| Порты | вход 0 Industrial In, вход 1 Power In, выход 0 Industrial Out, выход 1 Passthrough | префаб |
| Потребление | 1 (только для сортировки и проброса) | `IndustrialStorageAdaptor.ConsumptionAmount` |
| Проброс тока | вход − 1 | `GetCurrentEnergy` |

### Куда ставится

Сокеты `industrialstorageadaptor` / `adaptor0N` (`Socket_Specific_Female`) есть у:

| Контейнер | Сокетов |
|-----------|---------|
| Большой деревянный ящик и его скины | 4 |
| Маленький деревянный ящик | 2 |
| Шкаф (TC), включая скины retro и shockbyte | 2 |
| Шкафчик (`Locker`) | 3 — по одному на комплект |
| Большая печь | 4 |
| Маленькая печь, старая печь | 1 |
| Электропечь | 2 |
| Малая нефтеперегонка | 1 |
| Холодильник, мини-холодильник, настенный электрошкаф | 1 |
| Торговый автомат, почтовый ящик (`DropBox`), коновязь с кормушкой | 1 |

## Поведение

- **Питание для переноса не нужно.** Конвейер не проверяет питание адаптера.
- Адаптер — точка сети **и** проход: обход сети идёт через него дальше
  (`FindContainerSource`). Цепочкой «адаптер → адаптер» можно подключить к одному конвейеру
  несколько контейнеров без объединителя.
- **Шкафчик** отдаёт и принимает только 14 слотов одного комплекта, по позиции адаптера:
  правый сокет — слоты 0–13, центральный — 14–27, левый — 28–41 (`Locker.GetIndustrialSlotRange`).
  Одежду конвейер не положит в ряд пояса (`Locker.ItemFilter` с `isTransferringIndustrialItem`).
- **Торговый автомат** принимает предметы от конвейера в обход своих проверок
  (`industrialItemIncoming` в `CanAcceptItem`). Забрать из него конвейер может весь инвентарь —
  и товар, и выручку.
- Пока адаптер стоит, нельзя повернуть шкаф (`BuildingPrivlidge.RPC_Rotate`) и торговый автомат
  (`VendingMachine.CanRotate`), а шкафчик нельзя подобрать.

### Сортировка

С питанием адаптер умеет автоматически сортировать контейнер-родитель:

- работает только у контейнеров с `allowSorting = 1` в префабе: большой и маленький ящики
  со скинами, бочки, холодильники, настенный электрошкаф, торговый автомат, гроб.
  **Не работает** у печей, шкафа (TC) и шкафчиков;
- после любого изменения инвентаря сортировка ставится в очередь через 1 с; новое изменение
  сдвигает этот срок. Очередь `SortQueue` разбирается с бюджетом 0,1 мс за кадр;
- режимы: по имени (на выбранном языке), по количеству, по прочности (без прочности — в конец),
  по категории, по своему списку (до 64 коротких имён, чертежи с префиксом `bp`).
  Есть обратный порядок и «досыпать неполные стопки» (`stack`);
- сортировка сжимает предметы в слоты 0…n−1, то есть убирает дыры;
- выключается ConVar `server.allowSorting = false`.

## Нюансы

- **Настройки сортировки может менять кто угодно.** RPC `UpdatedStorageSettings` проверяет
  только видимость адаптера с 3 м, прав в шкафу не требует.
- **Сортировка срабатывает только с питанием** (`RequestSort` выходит при `!IsPowered()`).
  Без тока адаптер просто перевозит.
- Перенос конвейером не дёргает пересчёт инвентаря на каждый предмет:
  `OnIndustrialItemTransferBegins` / `End` откладывают `OnInventoryDirty` до конца тика.
- HP у адаптера всего 30 — меньше, чем у любого ящика.

## На практике

```
[Ящик 1]-адаптер ─► [Ящик 2]-адаптер ─► Конвейер ─► …   (оба ящика — источники)
```

- Ставьте адаптер на ящик-«склад» с питанием 1 и сортировкой по категории:
  после каждого привоза склад сам наводит порядок.
- Через адаптер на шкафу можно автоматически пополнять ресурсы на содержание из склада
  (лучше с фильтром Max).
