## Кратко

Блокировщик (`ElectricalBlocker`, префаб `electrical.blocker.deployed`, предмет
`electric.blocker`) — «выключатель, управляемый сигналом». Любое значение > 0 на входе
«Block Passthrough» обнуляет выход. Потребление 0.

## Характеристики

| Параметр | Значение | Источник |
|---|---|---|
| Вход 0 | «Power In», основной | префаб |
| Вход 1 | «Block Passthrough», **не** основной | префаб |
| Выход | «Power Out» | префаб |
| Потребление | 0 | `ConsumptionAmount` |
| HP | 200 | префаб |

## Поведение

- Вход 1 > 0 → флаг `On` (заблокирован). Выход = `вход 0 × (On ? 0 : 1)`.
- Флаг «запитан» (`Reserved8`) — по входу 0 (`input2Amount > 0`).
- `WantsPower`: пока блок включён, блокировщик сообщает, что питание ему не нужно. Батарея не
  считает нагрузку за ним. В режиме [[flicker|мерцания]] вход 0 «хочет» питания всегда.
- Смена блока вызывает `MarkDirty`, и выход пересчитывается через очередь ([[io-engine]]),
  не чаще раза в 0.1 с.

## Нюансы

- **Нет проверки петель.** Вход Block не основной. Выход блокировщика можно завести на его же
  вход Block (например, через [[splitter|сплиттер]]) и получить генератор колебаний с периодом
  около 0.2–0.3 с. Все устройства после него перейдут в режим мерцания. Подробно — [[flicker]].
- Закрытый блокировщик не разряжает батарею, а открытый передаёт спрос дальше. Это удобный
  способ «отключить» ветку без выключателя.
- `RANDSwitch` — наследник блокировщика с другой логикой, см. [[logic-gates]].

## На практике

- Инвертор: сигнал датчика на Block, постоянное питание на вход 0. Выход есть, пока датчик
  молчит.
- Блокировка турелей по сигналу: «Has Target» одной турели на Block цепи другой.

## Где в коде

`ElectricalBlocker.UpdateFromInput`, `UpdateBlocked`, `GetPassthroughAmount`, `WantsPower`, `UpdateHasPower`.
