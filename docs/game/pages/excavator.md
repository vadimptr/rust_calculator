## Кратко

`large/excavator_1.prefab` («Giant Excavator Pit»), `MinWorldSize = 3500`. В дизельный
двигатель (`DieselEngine`) кладут дизель, включают — ковш (`ExcavatorArm`) начинает копать
выбранный ресурс и раскладывает его поровну в две кучи-контейнера (`ExcavatorOutputPile`, по
36 слотов). Учёные: до 18 `scientistnpc_excavator` (3 + 3×5, ∞). Радиация одна зона `LOW`.
Переработчик есть.

## Характеристики

| Параметр | Значение | Откуда |
|----------|----------|--------|
| Время на 1 дизель | 120 с | `DieselEngine.runningTimePerFuelUnit` |
| Тик добычи | 1 с | `ExcavatorArm.resourceProductionTickRate` |
| Полная порция за | 120 с | `timeForFullResources` |
| МВК (`hq.metal.ore`) | 100 за 120 с | `resourcesToMine` |
| Сера (`sulfur.ore`) | 2000 за 120 с | `resourcesToMine` |
| Камень (`stones`) | 10000 за 120 с | `resourcesToMine` |
| Фрагменты металла | 5000 за 120 с | `resourcesToMine` |
| Компьютер связи: заряд на аирдроп | 600 (1 в секунду под током) | `ExcavatorSignalComputer.chargeNeededForSupplies` |
| Радио | частота 4777, пока двигатель работает | `RFBroadcaster.static`, `DummySwitch` «EngineListener» |
| Клановый счёт за запуск | 3 | `clan.scoreForRunningExcavator` |

То есть **1 дизель = ровно одна «полная порция»** выбранного ресурса, делится на 2 кучи.

## Поведение

1. Двигатель стартует, только если в слоте есть дизель (`EngineSwitch`); раз в 120 с
   съедает 1 единицу (`FixedUpdate` → `ConsumeFuelItem`).
2. При запуске двигатель шлёт `DieselEngineOn`: ковш получает питание, начинается
   `ProduceResources`, компьютер связи и сирены/радио включаются.
3. Каждую секунду в «копилку» выбранного ресурса добавляется `amount / 120`; как только
   набирается хотя бы по 1 штуке на кучу, целая часть раскладывается по кучам. Не влезло в
   кучу — выпадает рядом.
4. Компьютер связи заряжается на 1 за секунду, пока на него подан ток (`IsPowered`; по данным
   сообщества — пока работает экскаватор, в выгрузке сцены его проводка не видна); при 600
   можно вызвать грузовой самолёт с аирдропом в одну из точек сброса экскаватора (±3 м).

## Нюансы

- **Смена ресурса «перекрашивает» остаток.** `ProduceResources` раздаёт накопленные остатки
  **всех** ресурсов, но создаёт предмет **текущего** выбранного. Если переключить добычу,
  дробный остаток старого ресурса выдастся новым.
- Вычитание из копилки сделано как `num3 * 2` — жёстко под 2 кучи; при другом числе куч
  счёт бы разошёлся (в префабе куч ровно 2).
- Если компьютер питается от работы экскаватора, 600 с заряда = 5 дизелей = 1 аирдроп.
- Радио 4777 слышно, пока двигатель работает: соседи с RF-приёмником знают, что экскаватор
  запущен.

## На практике

- Сера — самый «плотный» выбор по ценности: 2000 серной руды за дизель.
- Забирайте из обеих куч: ресурс делится поровну.
- Вызывайте аирдроп каждые 5 дизелей — заряд не копится выше 600.
