## Кратко

Ячейка памяти (`ElectricalDFlipFlop`, префаб `electrical.memorycell.deployed`, предмет
`electrical.memorycell`) хранит один бит — флаг `On`. Весь вход питания она отдаёт на
«Output», когда включена, или на «Inverted Output», когда выключена. Не делит, не тратит:
потребление 0.

## Характеристики

| Слот | Назначение | Основной |
|---|---|---|
| Вход 0 | Power In | да |
| Вход 1 | Set | нет |
| Вход 2 | Reset | нет |
| Вход 3 | Toggle | нет |
| Выход 0 | Output (питание, если `On`) | — |
| Выход 1 | Inverted Output (питание, если не `On`) | — |

HP 200 (префаб).

## Поведение

```
GetDesiredState():
    Set > 0                → включить   (даже если Reset > 0)
    Reset > 0              → выключить
    Toggle > 0             → инвертировать
    иначе                  → оставить как есть

UpdateState() вызывается:
    • при любом изменении значения на Set, Reset или Toggle;
    • при КАЖДОМ обновлении входа питания (даже тем же значением)
    и работает, только если ячейка запитана (вход 0 > 0).
```

Выходы пересчитываются, только если состояние поменялось (`MarkDirtyForceUpdateOutputs`),
с обычным троттлингом 0.1 с ([[io-engine]]).

### Короткое замыкание

`DetectShortCircuit` проверяет вниз по выходам (`OutputsConnectedTo`, глубина 8): ведут ли
выходы обратно в саму ячейку. Если **оба** выхода возвращаются в неё — флаг `Reserved7`,
и все входящие сигналы, включая питание, обнуляются. Одна обратная связь разрешена.

### Мерцание

`AllowDrainFrom`: обычно батарея выше считает нагрузку только на активном выходе. При
[[flicker|мерцании]] — на обоих.

## Нюансы

- **Set сильнее Reset.** Оба > 0 → включено.
- **Toggle — не чистый фронт.** Пока на Toggle > 0, ячейка переключается при любом изменении
  значения Toggle (5 → 7) и при каждом обновлении входа питания. Если питание приходит со
  сплиттера или от устройства, которое часто «проталкивает» выходы, ячейка с зажатым
  Toggle может переключиться несколько раз. Подавайте на Toggle короткий импульс (кнопка,
  0.5 с) и стабильное питание.
- **Без питания не переключается.** Сигналы на Set/Reset/Toggle запоминаются, но состояние
  меняется, только когда ячейка запитана.
- Состояние хранится во флаге `On` и переживает рестарт сервера. Значения Set/Reset/Toggle
  (`[NonSerialized]`) — нет, они приходят заново от соседей.
- Ячейка отдаёт **весь** вход на один выход. Это основа трюка с мультиплексированием заряда
  батарей ([[flicker]]).

## На практике

- Защёлка сигнализации: датчик → Set, кнопка «сброс» → Reset, Output → сирена.
- Переключатель «одной кнопкой»: кнопка → Toggle.
- Переключение между двумя ветками без потерь: Output и Inverted Output — на разные
  потребители.
