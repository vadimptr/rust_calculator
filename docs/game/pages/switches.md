## Кратко

Все эти устройства управляют питанием по действию игрока или сигналу. Важные отличия:
обычный выключатель и кнопку может нажать **любой** игрок рядом, умный — только с правом
строительства. Кнопка и нажимная плита на полсекунды выдают ток даже без питания.

## Характеристики

| Устройство | Класс, префаб | Входы | Выход | Потребление | HP |
|---|---|---|---|---|---|
| Выключатель | `ElectricSwitch`, `switch` | Power In, Switch On, Switch Off | весь вход, если включён | 0 | 200 |
| Умный выключатель | `SmartSwitch`, `smartswitch` | Power In, Switch On, Switch Off | весь вход, если включён | 0 | 200 |
| Кнопка | `PressButton`, `button` | Power In | см. ниже | 0 | 200 |
| Нажимная плита | `PressurePad`, `pressurepad.deployed` | Power In | см. ниже | 0 | 200 |
| Дверной контроллер | `CustomDoorManipulator`, `doorcontroller.deployed` | Power In, Open, Close | Passthrough | 1 (базовое) | 200 |

## Поведение

### Выключатель и умный выключатель

- Сигнал > 0 на «Switch On» включает, на «Switch Off» — выключает. Обрабатывается в
  `UpdateHasPower`, срабатывает на каждое обновление с ненулевым значением.
- Выход = весь вход питания, пока включён (`GetPassthroughAmount`).
- `WantsPower` = true только во включённом состоянии: выключенный не тратит батарею.
- После переключения ставится флаг `Busy` на 0.5 с (для анимации). Сервер повторное
  переключение не блокирует.
- **Кто может щёлкнуть.** Обычный (`RPC_Switch`) — любой игрок в 3 м с прямой видимостью, без
  права строительства. Умный (`ToggleSwitch`) — только с `CanBuild`, не чаще 3 раз/с. Умный
  управляется ещё и из приложения Rust+ (`AppIOEntity`).

### Кнопка

```
нажатие (любой игрок, 3 м): On на pressDuration = 1 с, «вспышка» (Reserved3) на pressPowerTime = 0.5 с
во время вспышки: выход = max(pressPowerAmount = 2, вход питания)
после вспышки до отпускания: выход 0      // у игровой кнопки (есть sourceItem)
```

Значения — из префаба `button`. У монументных кнопок (без `sourceItem`, без `smallBurst`)
выход — просто вход питания, пока кнопка нажата.

### Нажимная плита

```
кто-то на плите (флаг Reserved1):
    первые pressPowerTime = 0.5 с: выход = max(pressPowerAmount = 1, вход)
    дальше: выход = вход, если плита запитана, иначе 0
плита пуста: выход 0
```

Плита — корневое устройство и срабатывает без питания (`ShouldTrigger` = true). Значения
из префаба `pressurepad.deployed` (в коде по умолчанию 2).

### Дверной контроллер

Ставится на дверь и привязывается к ней. Нужно право на замок двери
(`Door.GetPlayerLockPermission`).

```
питание появилось:   Close > 0 ? закрыть : открыть
питание пропало:     закрыть (если Open не держится)
Open: новое значение > 0 при питании  → открыть
Close: новое значение > 0 при питании → закрыть
дверь занята анимацией → повтор через 1 с
```

## Нюансы

- **Кнопка и плита — источники.** Без питания на входе они дают 2 и 1 rW на 0.5 с. Этого
  хватает для сигнальных входов: запуска генератора, Toggle ячейки памяти, Increment счётчика.
- **Игровая кнопка пропускает питание только 0.5 с**, хотя нажата 1 с.
- **Чужие руки.** Выключатель, кнопку и [[timer|таймер]] снаружи базы может нажать кто угодно.
  Для дверей и турелей снаружи используйте умный выключатель или кодовую логику.
- Сигнальные входы выключателя реагируют на каждое ненулевое обновление, а не на фронт.
  Если одновременно держатся On и Off, побеждает тот, что обновился последним.
- Контроллер сам по себе может открыть дверь при появлении питания — например, после
  рестарта сервера, когда схема перезапускается от корней ([[io-engine]]).

## На практике

- Внешний выключатель для гостей — только умный.
- Кнопка без питания + [[memory-cell|ячейка памяти]] = переключатель «вкл/выкл» с одним
  проводом питания.
- Плита у входа + [[timer|таймер]] = свет на время.
