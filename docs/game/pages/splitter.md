## Кратко

Сплиттер (`Splitter`, префаб `splitter`, предмет `electric.splitter`) — один вход, три выхода.
Потребление 0. Вход делится поровну между **подключёнными** выходами, остаток раздаётся
по единице первым из них. Тот же класс используется для воды (`fluidsplitter`) и индустрии
(`industrialsplitter.deployed`).

## Характеристики

| Параметр | Значение | Источник |
|---|---|---|
| Входы | 1 («Power In», основной) | префаб `splitter` |
| Выходы | 3 («Power Out 1–3») | префаб |
| Потребление | 0 | `Splitter.ConsumptionAmount` |
| HP | 500 (у большинства логики 200) | `startHealth` префаба |
| Корневое устройство | да | `Splitter.IsRootEntity` |

## Поведение

```
N    = число выходов, к которым подключено живое устройство
база = вход / N            (целочисленно)
ост  = вход % N
выход i получает база + 1, если он среди первых «ост» подключённых выходов по номеру слота
неподключённый выход получает 0
```

| Вход | Подключены | Выходы |
|---|---|---|
| 10 | 1, 2, 3 | 4 / 3 / 3 |
| 10 | 2, 3 | — / 5 / 5 |
| 2 | 1, 2, 3 | 1 / 1 / 0 |
| 1 | 2, 3 | — / 1 / 0 |

При изменении схемы выше (`OnCircuitChanged`) сплиттер всегда пересчитывает выходы
(`MarkDirtyForceUpdateOutputs`). Как корневое устройство он сам «перезапускает» свою часть
схемы после рестарта сервера ([[io-engine]]).

## Нюансы

- **Делит без учёта спроса.** Полная батарея или выключенный потребитель на выходе всё равно
  забирают свою долю, и она теряется. См. [[electricity-quirks]].
- **Не теряет остаток**, в отличие от обычных устройств с несколькими выходами.
- Провод к уничтоженному устройству не считается подключённым (`IsDestroyed`).
- Сплиттер — корневое устройство, поэтому его выход можно подавать в [[combiner|сумматор]]
  (у входов сумматора `rootConnectionsOnly`).
- Для батареи после сплиттера расход считается только по реальным потребителям, а не по
  доле сплиттера ([[battery]]).

## На практике

- Самого требовательного потребителя подключайте к выходу 1.
- Нужна точная мощность на одну ветку — берите [[electrical-branch|ветвитель]].
- Сплиттер как «переходник» к сумматору: сумматор не примет провод от неподходящего
  устройства, а от сплиттера примет.
