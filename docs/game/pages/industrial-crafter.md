## Кратко

Промышленный крафтер (`IndustrialCrafter`, префаб `industrialcrafter.deployed`) крепится
к сокету верстака. Внутри у него 13 слотов:

```
слоты 0–3   чертежи (только предметы-чертежи)
слоты 4–8   ингредиенты
слоты 9–12  готовое
```

Раз в ~5 с включённый крафтер просматривает чертежи по порядку и запускает крафт первого,
для которого хватает ресурсов и есть место на выходе.

## Характеристики

| Параметр | Значение | Источник |
|----------|----------|----------|
| HP | 200 | `startHealth` в префабе |
| Рецепт | 3 МВК, 2 техмусора, верстак 2, 30 с | чертёж `industrialcrafter.item` |
| Потребление | 1 | `IOEntity.ConsumptionAmount` |
| Интервал проверки | 5 с ± 2,5 с | `server.industrialCrafterFrequency` |
| Сокеты | 2 на верстаке 1, 2 и 3 уровня; 1 на IO-исследовательском столе (это `Workbench` 1 уровня) | `Socket_Specific_Female industrialcrafter*` в префабах |
| Права на открытие | не нужны | `NeedsBuildingPrivilegeToUse = 0` в префабе |
| Подбор | только с пустым инвентарём | `CanCompletePickup` |

### Порты

| Порт | Тип | Слоты |
|------|-----|-------|
| Вход 0 Industrial In | труба | кладёт в 4–8 |
| Вход 1 Power In | ток | питание |
| Вход 2 Toggle | ток | > 0 — включить (если есть питание), 0 — выключить |
| Вход 3 Blueprints In | труба | кладёт в 0–3 |
| Вход 4 Turn On / 5 Turn Off | ток | импульс включает или выключает |
| Выход 0 Industrial Out | труба | забирает из 9–12 |
| Выход 1 Blueprint Out | труба | забирает из 0–3 |

## Поведение

### Крафт (`IndustrialCrafter.RunJob`)

Для чертежей в слотах 0 → 3:

1. Пропуск, если крафтер не на верстаке (`GetParentEntity() as Workbench`) или уровень
   верстака ниже `GetWorkbenchLevel()` чертежа.
2. Ингредиенты ищутся **только в слотах 4–8** и только по точному предмету.
3. Нужен выходной слот, пустой или с тем же предметом и местом под `amountToCreate`.
   Нет места — ставится флаг «выход полон», и проверяется следующий чертёж.
4. Ингредиенты списываются сразу. Время крафта = `ItemBlueprint.GetCraftTime()`, при
   установленных апгрейдах верстака оно умножается на `Workbench.GetCraftSpeedMultiplier`.
5. По готовности (`CompleteCraft`) предмет помечается владельцем «Industrial Crafter».
   К нему применяются апгрейды верстака и бонусные предметы
   (`ApplyUpgradesToCraftedItem`, `CollectBonusItems`). Что не влезло в 9–12, падает на землю
   в 0,5 м перед крафтером.

Пока идёт крафт, новый не начинается. Один крафтер делает один предмет за раз.

### Время

- **Уровень верстака не ускоряет крафт.** Игрок у верстака на 1 уровень выше получает
  ×0,5 времени, на 2 уровня — ×0,25 (`ItemCrafter.GetScaledDuration`). Крафтер берёт базовое
  `GetCraftTime()` без этого (см. [[crafting]]).
- `GetCraftTime()` урезает время до 5 с для расходников. Для «штучных» предметов (оружие,
  одежда, стройка, ловушки) — до 5 + 10 × уровень верстака.
- Следующий крафт стартует только на ближайшей проверке. Реальный цикл = время крафта +
  ожидание до следующего тика (в среднем ~2,5 с, до ~7,5 с).

### Питание

- Пропало питание (вход 1 стал 0) — крафтер выключается и **сам не включается**,
  в отличие от конвейера: флага «был включён» у него нет.
- Начатый крафт при выключении не отменяется (`Invoke(CompleteCraft)` не снимается).
- Батарею крафтер разряжает только во включённом состоянии (`ShouldDrainBattery => IsOn()`).

## Нюансы

- **Чертёж не тратится и не должен быть изучен.** Нужна только бумага-чертёж в слотах 0–3.
  Изучать его никому не обязательно.
- **Приоритет — по номеру слота.** Если чертёж в слоте 0 всегда можно скрафтить, чертежи
  в 1–3 не получат очереди. Чертёж с переполненным выходом пропускается.
- **Рестарт сервера мгновенно заканчивает крафт.** При загрузке с диска `Load` сразу вызывает
  `CompleteCraft()` для сохранённого `currentlyCrafting`. Ингредиенты уже списаны, так что
  дюпа нет, но время досрочно «съедается».
- **Открыть крафтер может кто угодно** в 3 м прямой видимости: прав в шкафу не нужно,
  замка нет. Ресурсы и чертежи в нём не защищены.
- Чертежи можно положить и во входные слоты 4–8 — там ограничения нет, но крафтить по ним
  крафтер не будет.
- Ингредиенты должны быть ровно тем предметом из рецепта: скин-редиректы во входе не считаются
  (`GetInputAmount` сравнивает `def == slot.info`).

## На практике

```
[Ящик ресурсов]-адаптер ─► Конвейер ─► Crafter.Industrial In
Crafter.Industrial Out ─► Конвейер ─► адаптер-[Ящик готового]
Питание: батарея ─► Crafter.Power In; таймер/кнопка ─► Turn On
```

- Ставьте на подачу фильтр Max по каждому ингредиенту. Иначе 5 входных слотов забьются
  одним ресурсом, и для остальных не останется места.
- После перебоя питания крафтер нужно включить заново. Удобно завести на Turn On сигнал
  от того же источника через таймер.
- Для быстрых крафтов один крафтер упирается в ~5-секундный тик. Два крафтера на одном
  верстаке удваивают выпуск.
