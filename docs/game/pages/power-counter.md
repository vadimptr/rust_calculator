## Кратко

Счётчик (`PowerCounter`, префаб `counter`, предмет `electric.counter`) — один элемент в двух
режимах. В режиме счётчика он считает импульсы и открывает выход по достижении цели. В режиме
«passthrough» показывает, сколько rW проходит, и просто пропускает питание. Потребление 0.

## Характеристики

| Слот | Назначение |
|---|---|
| Вход 0 | Power In (основной) |
| Вход 1 | Increment Counter |
| Вход 2 | Decrement Counter |
| Вход 3 | Reset Counter |
| Выход 0 | Passthrough |

| Параметр | Значение | Источник |
|---|---|---|
| Максимум счёта | 999 (`MAX_VALUE`) | код |
| Цель | 1…999, по умолчанию 10 | `SERVER_SetTarget`, поле `targetCounterNumber` |
| Значение сброса | 0…999 | `resetTargetNumber` |
| Кто настраивает | игрок с правом строительства | `CanPlayerAdmin` |
| HP | 100 | префаб |

## Поведение

```
режим счётчика (флаг Reserved3 снят):
    Increment: значение > 0 → счёт + 1
    Decrement: значение > 0 → счёт − 1 (не ниже 0)
    Reset:     значение > 0 → счёт = значение сброса
    выход = (счёт ≥ цель) ? вход питания : 0

режим passthrough (Reserved3):
    выход = вход питания; сигналы на 1–3 игнорируются
```

## Нюансы

- **Считается каждое обновление со значением > 0, а не фронт.** Вызов
  `UpdateFromInput(5, 1)` два раза подряд — это +2. Обычно соседи не присылают одно и то же
  значение повторно (выходы обновляются только при изменении). Но устройство с несколькими выходами при изменении одного «проталкивает» все. Например,
  турель шлёт «Has Target», «Low Ammo» и «No Ammo» вместе: при каждом изменении
  числа патронов (`AutoTurret.UpdateTotalAmmo` → `MarkDirtyForceUpdateOutputs`, если подключён
  выход 1 или 2). Пока цель есть, счётчик на «Has Target» прибавляет 1 почти на каждый выстрел. Надёжнее подавать на Increment сигнал от кнопки или датчика
  напрямую.
- Счёт сохраняется (`genericInt1`) и переживает рестарт.
- В режиме счётчика `WantsPower` = true только когда цель достигнута. Батарея не тратится на
  потребителей за закрытым счётчиком.
- Выход открывается при «счёт ≥ цели», а не «= цели». Перебор не закрывает его.

## На практике

- Кодовый замок: кнопки → Increment/Reset, выход → дверной контроллер.
- Вольтметр: режим passthrough в разрыв провода показывает мощность.

## Где в коде

`PowerCounter.UpdateFromInput`, `GetPassthroughAmount`, `WantsPower`, `SERVER_SetTarget`, `ToggleDisplayMode`.
